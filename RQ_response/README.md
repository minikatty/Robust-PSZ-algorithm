# Major-revision experiments (`RQ_response`)

This directory contains the code added or substantially revised while
responding to the reviewers. It is separated from the core implementation so
that one-off diagnostics and manuscript experiments do not obscure the main
algorithm files.

## Main experiment map

| Purpose | Entry point |
|---|---|
| Matched full-band comparison | `run_all_algorithms_fair_evaluation.m` |
| Full-cross-term versus NoCT ablation | `run_wcracc_cross_term_ablation.m` |
| Raw/decomposed formulation comparison | `run_full_cross_term_racc_experiment.m` |
| Uncertainty-level sweep | `run_racc_pm_uncertainty_sweep.m` |
| RACC-PM trade-off-weight sweep | `run_racc_pm_rho_tradeoff_sweep.m` |
| SDP rank-recovery diagnostic | `run_racc_pm_rank_recovery_diagnostic.m` |
| Global versus row-block CPU benchmark | `benchmark_racc_pm_schur_pair.m` |
| SICER-VAST temperature reference | `run_sicer_vast_temperature_experiment.m` |
| Planarity and objective perceptual metrics | `run_planarity_perceptual_experiment.m` |
| Held-out measured-cabin evaluation | `run_final_measured_cabin_experiment.m` |
| Public demo export/provenance | `export_public_listening_demos.m` |

Companion analysis and plotting scripts in this folder consume the outputs of
these entry points. Generated results are intentionally excluded from Git.

## Reproducibility boundaries

- Run scripts from the repository root unless a script states otherwise.
- Temperature experiments require the generated database under
  `data/SimulateRIR/temperature/` and the plane-wave target generated by
  `generate_plane_wave_target.m`.
- The measured-cabin script documents the full protocol, but its industrial
  ATF dataset is not distributable.
- PESQ/PEAQ evaluation requires separately installed third-party software and
  properly licensed source audio.
- The 66 BZ/DZ listening WAV files already committed under `listening_demo/`
  can be inspected without any MATLAB dependency.

The numerical uncertainty level used by the optimizer is a radius of an
unstructured Frobenius ball. It should not be equated directly with the
maximum observed relative ATF deviation from a structured physical
perturbation such as temperature or human motion.

## Public demo regeneration

`export_public_listening_demos.m` expects two non-public/local inputs under
`RQ_response/private_inputs/` by default:

1. `broadband_renderers.mat`, generated by the completed perceptual pipeline;
2. `61-70968-0035.flac`, the selected LibriSpeech `test-clean` utterance.

Alternative paths can be passed explicitly. The exporter generates the music
and 1-kHz sources procedurally and never reads EBU SQAM material.
